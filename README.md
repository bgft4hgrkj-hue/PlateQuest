# 🚗 PlateQuest 🚗

A retro-styled road trip license plate tracking game!

## Features

✅ **Track all 50 US States + 13 Canadian Provinces + 5 US Territories**
- Interactive grid with visual feedback
- Click to mark regions as "seen"
- Fun trivia facts for each region

✅ **License Plate Logger**
- Log specific plates you've spotted
- Track by state/province
- Timestamped entries

✅ **Progress Tracking**
- Real-time progress bars
- Track completion percentage for US, Canada, and territories

✅ **Data Persistence**
- Auto-saves your progress to browser localStorage
- Resume where you left off

✅ **Undo Functionality**
- Undo your last action (mark/unmark or plate log)

✅ **Retro Aesthetic**
- Press Start 2P pixel font
- Neon color scheme (orange & cyan)
- Smooth animations
- Mobile-friendly responsive design

## How to Play

1. **Click a region** to mark it as "seen" - you'll get fun trivia!
2. **Log plates** using the sidebar tool - enter a plate number and select the state
3. **Check progress** with the 📊 PROGRESS button to see your completion
4. **Undo mistakes** with the ↩️ UNDO LAST ACTION button
5. **Track your adventure** - data is saved automatically!

## Getting Started

Simply open `index.html` in your web browser. No installation or dependencies required!
